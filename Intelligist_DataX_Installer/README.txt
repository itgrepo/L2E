คู่มือการติดตั้งระบบ Intelligist DataX (สำหรับ IT Support)
=============================================================

ไฟล์ในโฟลเดอร์นี้คือ Source Code และระบบฐานข้อมูลพร้อมใช้
สำหรับนำไป Deploy บน Server ผ่าน Docker Compose

สิ่งที่ต้องมีก่อนติดตั้ง:
1. Server ต้องติดตั้ง Docker และ Docker Compose เรียบร้อยแล้ว
2. Server ต้องสามารถเชื่อมต่อ Internet ได้ (สำหรับการดึง image พื้นฐาน)

ขั้นตอนการติดตั้งแบบด่วน:
------------------------------------------
1. เปิด Terminal แล้วเข้าไปที่โฟลเดอร์นี้
2. รันคำสั่งติดตั้งอัตโนมัติ:
   bash install.sh
3. รอจนกว่าระบบจะ Build Container และนำเข้าฐานข้อมูลเสร็จ
4. ระบบจะเปิดใช้งานที่ http://<ip_address>:3001

------------------------------------------
หากต้องการติดตั้งแบบแมนนวล (ทีละขั้นตอน):
------------------------------------------
1. Build และ Start Container:
   docker-compose up -d --build

2. รอประมาณ 20 วินาที เพื่อให้ MariaDB เริ่มทำงานสมบูรณ์

3. นำเข้าข้อมูลเริ่มต้นลง Database:
   docker exec -i datax_db_3001 mysql -uastro -ppassword123 datax_db_3001 < intelligist_datax_full_dump.sql

4. เสร็จสมบูรณ์! เข้าระบบผ่าน Browser http://<ip_address>:3001

------------------------------------------
ข้อมูลการตั้งค่าเพิ่มเติม (Port & Database):
- หากต้องการเปลี่ยน Port สามารถแก้ไขไฟล์ docker-compose.yml ได้เลย
- ฐานข้อมูลใช้ Port 3311 (ภายนอก) -> 3306 (ภายใน)
- Backend ใช้ Port 3011 (ภายนอก) -> 7000 (ภายใน)
- Frontend ใช้ Port 3001 (ภายนอก) -> 80 (ภายใน)
