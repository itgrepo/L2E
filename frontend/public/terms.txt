Gateway เป็นบริการดิจิทัล ภายใต้โครงการพัฒนาแพลตฟอร์มภาครัฐเพื่อรองรับการพัฒนาทักษะดิจิทัล เรียนรู้มีรายได้ เรียนรู้ง่ายตลอดชีวิต ผ่านรูปแบบ Learn to Earn ของ สํานักงานคณะกรรมการดิจิทัลเพื่อเศรษฐกิจ และสังคมแห่งชาติ (เรียกว่า “สํานักงาน”) สําหรับรวบรวม จัดทําบัญชีรายการ กํากับดูแล ค้นหา ขอใช้ เผยแพร่ และเชื่อมโยงแลกเปลี่ยนชุดข้อมูลผ่านระบบและ API เพื่อสนับสนุนการใช้ข้อมูลตามภารกิจที่เกี่ยวข้องกับการเรียนรู้ ทักษะ คุณวุฒิ สมรรถนะ และตลาดแรงงาน รวมถึงการวิเคราะห์ข้อมูลตามสิทธิที่ได้รับอนุญาต ข้อกําหนดและเงื่อนไขการใช้งานฉบับนี้ รวมถึงประกาศ นโยบาย เงื่อนไขประจําชุดข้อมูล และข้อกําหนดการใช้ API ที่แพลตฟอร์มเผยแพร่ในภายหลัง (เรียกรวมว่า “ข้อกําหนด”) เป็นข้อตกลงระหว่างท่านกับสํานักงานในการใช้บริการ การสมัครหรือใช้บริการต่อไปภายหลัง ที่ระบบแสดงข้อกําหนด ให้ถือว่าท่านได้อ่าน เข้าใจ และยอมรับข้อกําหนดนี้แล้ว หากท่านไม่ยอมรับข้อกําหนด โปรดงดสมัครหรือยุติการใช้บริการ  ข้อ 1 คําจํากัดความ 1.1 “แพลตฟอร์ม” หมายถึง Data Exchange Gateway หรือ Data Portal ตลอดจนเว็บไซต์ ระบบ แอปพลิเคชัน API และองค์ประกอบที่เกี่ยวข้อง 1.2 “ผู้ใช้งาน” หรือ “ท่าน” หมายถึงผู้ที่เข้าถึงแพลตฟอร์ม ผู้สมัครสมาชิก ผู้แทนหน่วยงาน ผู้ดูแลระบบ เจ้าของข้อมูล ผู้จัดทําชุดข้อมูล ผู้ขอใช้ข้อมูล หรือผู้ใช้ API แล้วแต่กรณี 1.3 “บัญชีผู้ใช้งาน” หมายถึงบัญชีเฉพาะบุคคลหรือบัญชีที่ได้รับมอบหมายให้ใช้บริการ ซึ่งผูกกับชื่อผู้ใช้ และวิธีพิสูจน์ตัวตนตามที่ระบบกําหนด 1.4 “ชุดข้อมูล” หรือ “Dataset” หมายถึงข้อมูล เนื้อหา ไฟล์ โครงสร้างข้อมูล หรือผลลัพธ์ที่ลงทะเบียน จัดเก็บ จัดทํา หรือเผยแพร่ผ่านแพลตฟอร์ม รวมถึง Metadata และ Data Dictionary 1.5 “API” ห มายถึงช่องท างเชื่อมต่อระห ว่างระบ บ เพื่ อเรียกใช้ ส่ง รับ  ห รือแลกเป ลี่ยนข้อมูล ตามขอบเขตสิทธิ์ที่กําหนด 1.6 “เจ้าของข้อมูล” หมายถึงหน่วยงานหรือบุคคลที่มีหน้าที่กําหนดวัตถุประสงค์ ระดับการเปิดเผย และเงื่อนไขการใช้ชุดข้อมูลตามอํานาจหน้าที่หรือสิทธิในข้อมูล 1.7 “ข้อมูลส่วนบุคคล” หมายถึงข้อมูลเกี่ยวกับบุคคลธรรมดาตามกฎหมายว่าด้วยการคุ้มครองข้อมูลส่วนบุคคล 
ข้อ 2 ขอบเขตการให้บริการของแพลตฟอร์ม แพลตฟอร์มประกอบด้วยระบบย่อยหลายส่วน ดังนี้  1. สมัครสมาชิก เข้าสู่ระบบ จัดการข้อมูลบัญชี และพิจารณาอนุมัติการสมัครหรือกําหนดบทบาทผู้ใช้งาน  2. จัดทําและค้นหา Data Catalog, Metadata และ Data Dictionary ของชุดข้อมูล  3. จัดเก็บ จัดหมวดหมู่ จัดเตรียม แปลง ผสม หรือสร้างชุดข้อมูลต้นแบบตามสิทธิที่ได้รับ  4. บริหาร API, Scope, Permission, สถานะการให้บริการ และการขออนุญาตเข้าถึงข้อมูล  5. เผยแพร่ชุดข้อมูลหรือ API แบบสาธารณะหรือแบบจํากัดสิทธิ์ ส่งออกข้อมูล และแชร์รายงานหรือ  Dashboard ตามเงื่อนไขของชุดข้อมูล  6. ติดตามการใช้งาน บันทึกเหตุการณ์ และจัดทํารายงานหรือ Dashboard เพื่อการบริหารจัดการ  ความมั่นคงปลอดภัย และการวิเคราะห์ข้อมูล สํานักงานอาจปรับปรุง เปลี่ยนแปลง เพิ่ม ลด หรือระงับบริการบางส่วนเท่าที่จําเป็นต่อการให้บริการ ความมั่นคง ปลอดภัย การปฏิบัติตามกฎหมาย หรือข้อกําหนดของเจ้าของข้อมูล โดยจะประกาศผ่านแพลตฟอร์ม หรือช่องทางที่เหมาะสม  ข้อ 3 การสมัครสมาชิก การอนุมัติ และความปลอดภัยของบัญชี 3.1 ท่านต้องให้ข้อมูลที่ถูกต้อง ครบถ้วน และเป็นปัจจุบันในการสมัคร เช่น ชื่อผู้ใช้ อีเมล ชื่อ นามสกุล และ หน่วยงานหรือองค์กร ตามที่ระบบแสดงและต้องมีอํานาจกระทําการแทนหน่วยงานเมื่อสมัคร ในนามหน่วยงาน 3.2 การสมัครสมาชิกไม่ได้ทําให้ท่านมีสิทธิเข้าถึงข้อมูลทุกชุดโดยอัตโนมัติ การใช้บริการหรือข้อมูลบางประเภท อาจต้องได้รับการอนุมัติ กําหนดบทบาท หรือกําหนดขอบเขตสิทธิ์เพิ่มเติมจากผู้ดูแลระบบหรือเจ้าของข้อมูล 3.3 บัญชีผู้ใช้งานเป็นสิทธิเฉพาะตัว ห้ามโอน ให้ยืม เปิดเผยรหัสผ่าน หรืออนุญาตให้ผู้อื่นใช้บัญชีแทน ท่านต้อง เก็บรักษาข้อมูลรับรองการเข้าสู่ระบบให้ปลอดภัย และแจ้งสํานักงานโดยเร็วเมื่อสงสัยว่ามีการเข้าถึง บัญชีโดยมิชอบ 3.4 การดําเนินการผ่านบัญชีของท่านจะถือว่าเกิดจากท่านหรือผู้ที่ท่านอนุญาต เว้นแต่ท่านพิสูจน์ได้โดย สมเหตุสมผลว่าเกิดจากความบกพร่องของแพลตฟอร์มหรือการเข้าถึงโดยมิชอบที่มิได้เกิดจากการฝ่าฝืนหน้าที่ของท่าน      
ข้อ 4 การเข้าถึง การใช้ และการแลกเปลี่ยนข้อมูล 4.1 ผู้ใช้งานทั่วไปอาจเข้าถึงได้เฉพาะ Metadata หรือข้อมูลที่เจ้าของข้อมูลอนุมัติให้เผยแพร่เป็นสาธารณะ ส่วนข้อมูลแบบจํากัดสิทธิ์หรือข้อมูลภายใน ต้องยื่นคําขอและได้รับอนุมัติตามขั้นตอนที่ระบบกําหนดก่อนเข้าถึง 4.2 สิทธิ์เข้าถึงอาจกําหนดตามบทบาท ผู้ใช้ กลุ่มผู้ใช้ ชุดข้อมูล API Scope ฟิลด์ข้อมูล วัตถุประสงค์ ระยะเวลา ปริมาณการเรียกใช้ หรือเงื่อนไขอื่นตามที่เจ้าของข้อมูลกําหนด ผู้ใช้งานต้องใช้ข้อมูลภายในขอบเขต ดังกล่าวเท่านั้น 4.3 การส่งออก ดาวน์โหลด ส่งต่อ เผยแพร่ ทําสําเนา หรือใช้ข้อมูลต่อ ต้องเป็นไปตามระดับการเปิดเผย ใบอนุญาต เงื่อนไขประจําชุดข้อมูล และกฎหมายที่เกี่ยวข้อง หากชุดข้อมูลระบุแหล่งที่มา ผู้ใช้งานต้อง อ้างอิงแหล่งที่มาตามสมควร 4.4 ผู้ที่นําเข้าหรือเผยแพร่ชุดข้อมูลต้องรับรองว่าเป็นเจ้าของข้อมูลหรือได้รับสิทธิและมีฐานทางกฎหมาย เพียงพอในการนําข้อมูลเข้าสู่แพลตฟอร์ม รวมทั้งกําหนด Metadata ระดับการเปิดเผย เงื่อนไขการใช้ และมาตรการคุ้มครองข้อมูลที่เหมาะสม 4.5 ห้ามนําข้อมูลส่วนบุคคล ข้อมูลอ่อนไหว ข้อมูลลับ หรือข้อมูลที่มีข้อจํากัดตามกฎหมายเข้าสู่หรือเผยแพร่ ผ่านแพลตฟอร์ม เว้นแต่ได้รับอนุญาตตามกฎหมายและได้กําหนดมาตรการคุ้มครอง การจํากัดสิทธิ์ และเงื่อนไขการใช้ข้อมูลอย่างเหมาะสมแล้ว  ข้อ 5 หน้าที่และข้อห้ามของผู้ใช้งาน  ผู้ใช้งานต้องปฏิบัติตามกฎหมาย ข้อกําหนดนี้ และเงื่อนไขของชุดข้อมูลหรือ API ที่ใช้ และตกลง ว่าจะไม่กระทําการดังต่อไปนี้ 5.1 เข้าถึง ใช้ คัดลอก เปลี่ยนแปลง ทําลาย หรือเปิดเผยข้อมูลนอกเหนือจากสิทธิและวัตถุประสงค์ที่ได้รับอนุมัติ 5.2 นําข้อมูลไปใช้เพื่อระบุตัวบุคคล ติดตามบุคคล ทําการตลาด เลือกปฏิบัติ หรือก่อให้เกิดความเสียหาย เว้นแต่ มีอํานาจและฐานทางกฎหมายรองรับโดยชัดแจ้ง 5.3 นําข้อมูลของผู้อื่น ข้อมูลที่ละเมิดลิขสิทธิ์ ข้อมูลผิดกฎหมาย มัลแวร์ หรือข้อมูลที่อาจกระทบ ความมั่นคงปลอดภัยเข้าสู่ระบบ 5.4 พยายามหลีกเลี่ยงหรือฝ่าฝืนมาตรการพิสูจน์ตัวตน การกําหนดสิทธิ์ การจํากัดอัตราการเรียกใช้ หรือ มาตรการรักษาความมั่นคงปลอดภัยของแพลตฟอร์ม 5.5 ใช้โปรแกรมอัตโนมัติหรือวิธีการใดเพื่อดึงข้อมูลจํานวนมาก ส่งคําขอเกินสมควร หรือกระทําการ ที่กระทบเสถียรภาพของระบบ เว้นแต่ได้รับอนุญาตผ่าน API หรือช่องทางที่กําหนด 5.6 แอบอ้างบุคคลหรือหน่วยงานอื่น ให้ข้อมูลอันเป็นเท็จ หรือใช้บัญชีของผู้อื่นโดยไม่ได้รับอนุญาต  
ข้อ 6 ความถูกต้องของข้อมูล ข้อจํากัด และข้อสงวนสิทธิ์ 6.1 ข้อมูล ชุดข้อมูล รายงานหรือผลการวิเคราะห์ที่ปรากฏในแพลตฟอร์มอาจมาจากเจ้าของข้อมูลหรือ แหล่งข้อมูลภายนอก สํานักงานจะดําเนินการตามสมควรเพื่อให้บริการอย่างต่อเนื่อง แต่ไม่รับรองว่าข้อมูลทุกส่วน จะถูกต้อง ครบถ้วน เป็นปัจจุบัน หรือเหมาะสมกับวัตถุประสงค์เฉพาะของท่าน 6.2 ผลการค้นหา การจัดกลุ่ม การเชื่อมโยง การคํานวณ รายงาน หรือ Dashboard เป็นข้อมูลเพื่อประกอบ การพิจารณา ผู้ใช้งานต้องตรวจสอบความเหมาะสม ความถูกต้อง และข้อจํากัดของข้อมูลก่อนนําไปใช้ ตัดสินใจหรือดําเนินการใด 6.3 แพลตฟอร์มอาจเชื่อมต่อกับบริการหรือแหล่งข้อมูลของบุคคลภายนอก การใช้บริการดังกล่าวอยู่ภายใต้ เงื่อนไขและนโยบายของผู้ให้บริการหรือเจ้าของข้อมูลนั้น สํานักงานไม่รับผิดชอบต่อเนื้อหา ความพร้อมใช้ หรือการดําเนินการของบุคคลภายนอก เว้นแต่กฎหมายกําหนดเป็นอย่างอื่น 6.4 สํานักงานไม่รับผิดชอบต่อความเสียหายที่เกิดจากการใช้ข้อมูลเกินสิทธิ ผิดวัตถุประสงค์ หรือฝ่าฝืนเงื่อนไข ของชุดข้อมูลโดยผู้ใช้งาน ทั้งนี้ ไม่เป็นการจํากัดความรับผิดที่กฎหมายไม่อนุญาตให้จํากัด  ข้อ 7 การระงับหรือยกเลิกการให้บริการ  สํานักงานอาจระงับ จํากัด หรือยกเลิกบัญชี สิทธิ์ หรือการให้บริการทั้งหมดหรือบางส่วน เมื่อมีเหตุ อันสมควร รวมถึงกรณีต่อไปนี้ 7.1 มีความจําเป็นในการบํารุงรักษา แก้ไขข้อขัดข้อง ปรับปรุงระบบ หรือป้องกันเหตุด้านความมั่นคงปลอดภัย 7.2 ท่านฝ่าฝืนข้อกําหนด กฎหมาย เงื่อนไขของชุดข้อมูล หรือคําสั่งของผู้มีอํานาจ 7.3 พบหรือสงสัยโดยสมเหตุสมผลว่ามีการใช้บัญชีหรือข้อมูลโดยมิชอบ มีความเสี่ยงต่อข้อมูลส่วนบุคคล ความลับ หรือความมั่นคงปลอดภัย 7.4 สิทธิ์ของท่านหมดอายุ ถูกเพิกถอน หรือเจ้าของข้อมูลเปลี่ยนแปลงระดับการเปิดเผยหรือเงื่อนไขการใช้ข้อมูล 7.5 สํานักงานจะใช้ความพยายามตามสมควรในการแจ้งผลการระงับหรือยกเลิก เว้นแต่การแจ้งอาจกระทบ ต่อการรักษาความมั่นคงปลอดภัย การสืบสวน หรือการปฏิบัติตามกฎหมาย  ข้อ 8 ข้อมูลส่วนบุคคล  สํานักงานประมวลผลข้อมูลส่วนบุคคลเท่าที่จําเป็นต่อการให้บริการ การบริหารสิทธิ์ การรักษา ความมั่นคงปลอดภัย และการปฏิบัติตามกฎหมาย รายละเอียดเกี่ยวกับประเภทข้อมูล วัตถุประสงค์ ฐานการประมวลผล ผู้รับข้อมูล ระยะเวลาการเก็บรักษา และสิทธิของเจ้าของข้อมูล ปรากฏในคําประกาศเกี่ยวกับ ความเป็นส่วนตัวของแพลตฟอร์ม  
ข้อ 9 ทรัพย์สินทางปัญญาและสิทธิในข้อมูล  สิทธิในซอฟต์แวร์ การออกแบบ เครื่องหมาย ชื่อ และองค์ประกอบของแพลตฟอร์มเป็นของสํานักงาน หรือผู้ให้สิทธิ์แก่สํานักงาน การเข้าถึงแพลตฟอร์มไม่เป็นการโอนสิทธิในทรัพย์สินทางปัญญาดังกล่าวแก่ผู้ใช้งาน สิทธิในชุดข้อมูลยังเป็นของเจ้าของข้อมูลหรือผู้ทรงสิทธิตามกฎหมาย การใช้ชุดข้อมูลต้องเป็นไปตามใบอนุญาต เงื่อนไข หรือข้อจํากัดที่ระบุไว้กับชุดข้อมูลนั้น  ข้อ 10 การติดต่อและการแจ้ง  สํานักงานอาจติดต่อหรือแจ้งข้อมูลผ่านอีเมลที่ท่านลงทะเบียนไว้ การแจ้งเตือนในระบบ หรือประกาศ บนแพลตฟอร์ม ผู้ใช้งานต้องตรวจสอบและปรับปรุงข้อมูลติดต่อให้เป็นปัจจุบัน การแจ้งผ่านช่องทางดังกล่าว ให้มีผลเมื่อระบบแสดงหรือส่งตามวิธีปกติ เว้นแต่กฎหมายกําหนดเป็นอย่างอื่น  ข้อ 11 ความสมบูรณ์ของข้อกําหนด  หากข้อกําหนดส่วนหนึ่งส่วนใดเป็นโมฆะ ใช้บังคับไม่ได้ หรือไม่สมบูรณ์ตามกฎหมาย ให้แยกส่วนนั้น ออกโดยไม่กระทบต่อความสมบูรณ์และการบังคับใช้ของข้อกําหนดส่วนที่เหลือ  ข้อ 12 กฎหมายที่ใช้บังคับและการระงับข้อพิพาท  ข้อกําหนดนี้อยู่ภายใต้กฎหมายแห่งราชอาณาจักรไทย หากเกิดข้อพิพาท คู่กรณีจะพยายามเจรจาโดย สุจริตก่อน และหากไม่สามารถยุติข้อพิพาทได้ ให้ดําเนินการตามกระบวนการและศาลที่มีเขตอํานาจตามกฎหมาย  ข้อ 13 การปรับปรุงข้อกําหนด  สํานักงานอาจปรับปรุงข้อกําหนดให้สอดคล้องกับบริการ กฎหมาย หรือมาตรการความมั่นคงปลอดภัย โดยจะแจ้งฉบับปรับปรุงและวันที่มีผลบังคับใช้ผ่านแพลตฟอร์มหรือช่องทางที่เหมาะสม การใช้บริการต่อ ภายหลังวันที่มีผลบังคับใช้ ให้ถือว่าท่านยอมรับข้อกําหนดฉบับปรับปรุงเท่าที่กฎหมายอนุญาต  ช่องทางติดต่อ สํานักงานคณะกรรมการดิจิทัลเพื่อเศรษฐกิจและสังคมแห่งชาติ 120 หมู่ 3 ชั้น 3 และ 5 ศูนย์ราชการเฉลิมพระเกียรติฯ (อาคารซี) ซอยแจ้งวัฒนะ 7 ถนนแจ้งวัฒนะ แขวงทุ่งสองห้อง เขตหลักสี่ กรุงเทพมหานคร 10210 โทรศัพท์ 0 2142 1202 | อีเมล saraban@bde.go.th
