คําประกาศเกี่ยวกับความเป็นส่วนตัว (Privacy Notice) แพลตฟอร์ม Data Exchange Gateway (Data Portal)  ภายใต้โครงการพัฒนาแพลตฟอร์มภาครัฐเพื่อรองรับการพัฒนาทักษะดิจิทัล  เรียนรู้มีรายได้ เรียนรู้ง่ายตลอดชีวิต ผ่านรูปแบบ Learn to Earn  1. บทนําและผู้ควบคุมข้อมูลส่วนบุคคล  คําประกาศเกี่ยวกับความเป็นส่วนตัวฉบับนี้ (เรียกว่า “คําประกาศ”) อธิบายวิธีที่สํานักงาน คณะกรรมการดิจิทัลเพื่อเศรษฐกิจและสังคมแห่งชาติ (เรียกว่า “สํานักงาน” หรือ “เรา”) เก็บรวบรวม ใช้ เปิดเผย เก็บรักษา และคุ้มครองข้อมูลส่วนบุคคลของผู้ใช้แพลตฟอร์ม Data Exchange Gateway (เรียกว่า “แพลตฟอร์ม”) ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 และกฎหมายที่เกี่ยวข้อง สําหรับการ ประมวลผลข้อมูลบัญชี การให้บริการแพลตฟอร์ม การบริหารสิทธิ์ และความมั่นคงปลอดภัยของระบบ สํานักงานเป็นผู้ควบคุมข้อมูลส่วนบุคคล ทั้งนี้ ในกรณีที่ชุดข้อมูลหนึ่งมีหน่วยงานอื่นเป็นเจ้าของข้อมูล หน่วยงานเจ้าของข้อมูลอาจเป็นผู้ควบคุมข้อมูลส่วนบุคคลสําหรับข้อมูลในชุดข้อมูลนั้น และอาจมี ประกาศหรือเงื่อนไขเฉพาะเพิ่มเติม ผู้ใช้ควรอ่านประกาศและเงื่อนไขของชุดข้อมูลก่อน ขอเข้าถึงหรือใช้ข้อมูล  2. ข้อมูลส่วนบุคคลที่เราเก็บรวบรวม  เราเก็บรวบรวมข้อมูลเท่าที่จําเป็นตามบทบาทและบริการที่ท่านใช้ โดยอาจรวมถึงข้อมูลต่อไปนี้ 2.1 ข้อมูลบัญชีและข้อมูลติดต่อ: ชื่อผู้ใช้ อีเมล ชื่อ นามสกุล หน่วยงานหรือองค์กร บทบาท สถานะบัญชี และข้อมูลที่ท่านให้ผ่านการสมัครสมาชิกหรือการจัดการโปรไฟล์ รหัสผ่านจะได้รับการคุ้มครองด้วยวิธีทางเทคนิค ที่เหมาะสม และไม่แสดงให้ผู้ดูแลระบบเห็นเป็นข้อความปกติ 2.2 ข้อมูลการขอสิทธิ์และการใช้บริการ: รายละเอียดคําขอเข้าถึงชุดข้อมูลหรือ API วัตถุประสงค์ ขอบเขตสิทธิ์ สถานะการอนุมัติ ชุดข้อมูลหรือ API ที่เกี่ยวข้อง วันที่ลงทะเบียน วันที่อนุมัติ และการตั้งค่าการแจ้งเตือน 2.3 ข้อมูลการใช้งานและบันทึกเหตุการณ์: ข้อมูลการเข้าสู่ระบบ การเปลี่ยนแปลงบัญชี การจัดการชุดข้อมูลหรือ API การเรียกใช้บริการ ความพยายามเข้าถึง และบันทึกการดําเนินการอื่นในระบบ เพื่อการตรวจสอบ และรักษาความมั่นคงปลอดภัย 2.4 ข้อมูลที่อยู่ในชุดข้อมูลหรือเอกสารที่นําเข้า: ข้อมูลติดต่อของผู้ประสานงาน เจ้าของข้อมูล ผู้ดูแลข้อมูล หรือข้อมูลส่วนบุคคลอื่นที่ปรากฏในไฟล์ ชุดข้อมูล Metadata หรือ Data Dictionary ที่ผู้ใช้งานหรือหน่วยงาน นําเข้าสู่แพลตฟอร์ม หากมีความจําเป็นและได้รับอนุญาตตามกฎหมาย 
2.5 ข้อมูลการติดต่อ: ชื่อ อีเมล หน่วยงาน และรายละเอียดคําถาม ข้อเสนอแนะ หรือปัญหาที่ท่านส่งผ่าน ช่องทางติดต่อหรือขอรับการสนับสนุน  แพลตฟอร์มไม่ได้กําหนดให้ผู้สมัครสมาชิกต้องให้ข้อมูลส่วนบุคคลอ่อนไหวและขอให้ท่านหลีกเลี่ยงการนําข้อมูล อ่อนไหวเข้าสู่แพลตฟอร์ม เว้นแต่จําเป็น มีฐานกฎหมาย และมีมาตรการคุ้มครองตามกฎหมายและเงื่อนไข ของเจ้าของข้อมูลแล้ว  3. แหล่งที่มาของข้อมูล  เราอาจได้รับข้อมูลส่วนบุคคลจากแหล่งต่อไปนี้ 3.1 จากท่านโดยตรงเมื่อสมัครสมาชิก กรอกหรือแก้ไขข้อมูล ส่งคําขอใช้ข้อมูลติดต่อเราหรือใช้บริการแพลตฟอร์ม 3.2 จากผู้ดูแลระบบ หน่วยงานหรือองค์กรของท่าน เมื่อมีการสร้างบัญชี กําหนดบทบาท หรืออนุมัติสิทธิ์แทนท่าน 3.3 จากเจ้าของข้อมูลหรือหน่วยงานผู้ให้ข้อมูล เมื่อมีการเชื่อมโยง นําเข้า หรือปรับปรุงชุดข้อมูลตามข้อตกลง และกฎหมายที่เกี่ยวข้อง 3.4 จากการทํางานของระบบ เช่น บันทึกการเข้าสู่ระบบ บันทึกการใช้ API และบันทึกเหตุการณ์ด้านความมั่นคง ปลอดภัย  4. วัตถุประสงค์และฐานทางกฎหมายในการประมวลผล  เราอาจประมวลผลข้อมูลส่วนบุคคลเพื่อวัตถุประสงค์ดังต่อไปนี้โดยอาศัยฐานกฎหมายที่เหมาะสมตามแต่กรณี เช่น การปฏิบัติภารกิจเพื่อประโยชน์สาธารณะหรือการใช้อํานาจรัฐ การปฏิบัติตามกฎหมาย การปฏิบัติ ตามสัญญาหรือคําขอก่อนเข้าทําสัญญา ประโยชน์โดยชอบด้วยกฎหมาย หรือความยินยอม 4.1 เพื่อสร้างและบริหารบัญชี ยืนยันตัวตน จัดการบทบาท และให้บริการตามที่ท่านร้องขอ 4.2 เพื่อรับ พิจารณา อนุมัติ ปฏิเสธ ทบทวน หรือเพิกถอนคําขอเข้าถึงชุดข้อมูลและ API ตามนโยบายของ เจ้าของข้อมูล 4.3 เพื่อจัดทํา Data Catalog, Metadata, Data Dictionary และจัดการวงจรชีวิตของชุดข้อมูลหรือ API 4.4 เพื่อป้องกัน ตรวจสอบ วิเคราะห์ และแก้ไขเหตุด้านความมั่นคงปลอดภัย การใช้บริการโดยมิชอบ และการปฏิบัติตามข้อกําหนด 4.5 เพื่อจัดทําสถิติ รายงาน และ Dashboard เกี่ยวกับการใช้งาน การขอสิทธิ์ หรือประสิทธิภาพของระบบ โดยใช้ข้อมูลเท่าที่จําเป็นและมีมาตรการคุ้มครองที่เหมาะสม 4.6 เพื่อติดต่อ แจ้งผลการสมัครหรือคําขอ แจ้งเหตุด้านระบบ ตอบข้อซักถาม และดําเนินการตามคําร้องของท่าน 4.7 เพื่อปฏิบัติตามกฎหมาย คําสั่งของหน่วยงานที่มีอํานาจ และการตรวจสอบที่ชอบด้วยกฎหมาย   
5. การเปิดเผยหรือส่งต่อข้อมูลส่วนบุคคล  เราอาจเปิดเผยหรือส่งต่อข้อมูลส่วนบุคคลเท่าที่จําเป็นแก่ผู้รับข้อมูลต่อไปนี้ 5.1 เจ้าหน้าที่หรือผู้ดูแลระบบที่ได้รับมอบหมายและมีหน้าที่เกี่ยวข้อง โดยเข้าถึงตามบทบาทและ หลักความจําเป็น 5.2 เจ้าของข้อมูล หน่วยงานผู้ให้ข้อมูล หรือผู้มีอํานาจอนุมัติสิทธิ์ เพื่อพิจารณาและกํากับการเข้าถึงชุดข้อมูลหรือ API 5.3 ผู้ให้บริการโครงสร้างพื้นฐาน ระบบคลาวด์ ระบบรักษาความมั่นคงปลอดภัย หรือผู้ให้บริการสนับสนุนอื่น ที่ทําหน้าที่เป็นผู้ประมวลผลข้อมูลส่วนบุคคลตามสัญญาหรือคําสั่งของเรา 5.4 ผู้ใช้งานหรือหน่วยงานที่ได้รับสิทธิ์เข้าถึงข้อมูลตามคําขอและเงื่อนไขของชุดข้อมูล โดยเฉพาะเมื่อท่านเป็น ผู้เผยแพร่หรือระบุให้เปิดเผยข้อมูลดังกล่าว 5.6 หน่วยงานของรัฐ หน่วยงานกํากับดูแล หรือบุคคลที่มีอํานาจตามกฎหมาย เมื่อมีหน้าที่ต้องเปิดเผย หรือส่งข้อมูล 5.7 เราไม่ขายข้อมูลส่วนบุคคล และจะไม่เปิดเผยข้อมูลนอกเหนือจากวัตถุประสงค์หรือฐานกฎหมายที่เกี่ยวข้อง เว้นแต่ได้รับความยินยอม หรือกฎหมายอนุญาต  6. การส่งหรือโอนข้อมูลไปต่างประเทศ  หากมีความจําเป็นต้องส่งหรือโอนข้อมูลส่วนบุคคลไปยังต่างประเทศ เราจะดําเนินการให้เป็นไป ตามหลักเกณฑ์ของกฎหมายคุ้มครองข้อมูลส่วนบุคคล และจัดให้มีมาตรการคุ้มครองที่เหมาะสม ก่อนการโอนตามความจําเป็น  7. ระยะเวลาการเก็บรักษาข้อมูล  เราเก็บรักษาข้อมูลส่วนบุคคลไว้เท่าที่จําเป็นต่อวัตถุประสงค์ที่แจ้งไว้ การให้บริการ การรักษาความมั่นคง ปลอดภัย การตรวจสอบสิทธิ์ และการปฏิบัติตามกฎหมาย โดยพิจารณาลักษณะของข้อมูลและข้อกําหนด ของเจ้าของข้อมูลเป็นสําคัญ 7.1 ข้อมูลบัญชีและข้อมูลการติดต่อ: ตลอดระยะเวลาที่บัญชียังใช้งาน หรือเท่าที่จําเป็นต่อการจัดการบัญชี และการติดต่อหลังบัญชีสิ้นสุด 7.2 ข้อมูลคําขออนุญาตและสิทธิ์เข้าถึง: ตลอดอายุสิทธิ์และเท่าที่จําเป็นสําหรับการตรวจสอบย้อนหลัง หรือการ จัดการข้อพิพาท 7.3 บันทึกเหตุการณ์และข้อมูลด้านความมั่นคงปลอดภัย: ตามระยะเวลาที่จําเป็นเพื่อความมั่นคงปลอดภัย การตรวจสอบ และข้อกําหนดตามกฎหมาย 
7.4 ข้อมูลในชุดข้อมูลที่นําเข้า: ตามวัตถุประสงค์ ระยะเวลาการให้บริการ และเงื่อนไขที่เจ้าของข้อมูล หรือกฎหมายกําหนด 7.5 เมื่อหมดความจําเป็น เราจะลบ ทําลาย หรือทําให้ข้อมูลไม่สามารถระบุตัวบุคคลได้ เว้นแต่กฎหมายหรือ การใช้สิทธิเรียกร้องตามกฎหมายกําหนดให้เก็บรักษาไว้นานกว่า  8. คุกกี้และเทคโนโลยีที่คล้ายกัน  แพลตฟอร์มอาจใช้คุกกี้ โทเคน หรือเทคโนโลยีที่จําเป็นต่อการยืนยันตัวตน การคงสถานะการใช้งาน ความปลอดภัย และการทํางานของระบบ หากมีการใช้คุกกี้หรือเทคโนโลยีเพื่อวัตถุประสงค์อื่น เราจะจัดให้ มีประกาศหรือกลไกที่เหมาะสมตามกฎหมาย  9. สิทธิของเจ้าของข้อมูลส่วนบุคคล  ภายใต้เงื่อนไขและข้อยกเว้นตามกฎหมาย ท่านอาจมีสิทธิขอเข้าถึงและรับสําเนาข้อมูล ขอรับหรือ โอนย้ายข้อมูล ขอแก้ไขข้อมูลให้ถูกต้อง ขอให้ลบหรือทําลายข้อมูล ขอให้ระงับการใช้ข้อมูล คัดค้านการ ประมวลผล ถอนความยินยอม และร้องเรียนต่อหน่วยงานกํากับดูแลที่มีอํานาจ  ท่านสามารถยื่นคําขอใช้สิทธิผ่านช่องทางติดต่อในข้อ 12 เราอาจขอข้อมูลเพิ่มเติมเพื่อยืนยันตัวตน หรือพิจารณาคําขอตามกฎหมาย หากข้อมูลเกี่ยวข้องกับชุดข้อมูลของ หน่วยงานอื่น เราอาจประสานหรือส่งคําขอ ไปยังเจ้าของข้อมูลที่เกี่ยวข้อง  10. ผลของการไม่ให้ข้อมูลส่วนบุคคล  ข้อมูลบางรายการเป็นข้อมูลจําเป็นต่อการสมัครสมาชิก การยืนยันตัวตน การอนุมัติสิทธิ์ หรือการรักษา ความมั่นคงปลอดภัย หากท่านไม่ให้ข้อมูลที่จําเป็น เราอาจไม่สามารถสร้างบัญชี พิจารณาคําขอ หรือให้บริการ บางส่วนแก่ท่านได้  11. มาตรการรักษาความมั่นคงปลอดภัย  เราใช้มาตรการด้านการบริหารจัดการและเทคนิคที่เหมาะสมกับความเสี่ยง เช่น การกําหนดสิทธิ์ตาม บทบาทและขอบเขตสิทธิ์ การจํากัดการเข้าถึงข้อมูลแบบ Public/Private การคุ้มครองรหัสผ่าน การบันทึก และติดตามเหตุการณ์ การตรวจสอบสิทธิ์การใช้ API และการทบทวนการเข้าถึงข้อมูล เพื่อป้องกันการสูญหาย เข้าถึง ใช้ เปลี่ยนแปลง หรือเปิดเผยข้อมูลโดยไม่ได้รับอนุญาต   
12. ช่องทางติดต่อและการใช้สิทธิ หากท่านมีคําถามเกี่ยวกับคําประกาศนี้ ต้องการใช้สิทธิ หรือประสงค์ติดต่อเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล โปรดติดต่อ สํานักงานคณะกรรมการดิจิทัลเพื่อเศรษฐกิจและสังคมแห่งชาติ 120 หมู่ 3 ชั้น 3 และ 5 ศูนย์ราชการเฉลิมพระเกียรติฯ (อาคารซี) ซอยแจ้งวัฒนะ 7 ถนนแจ้งวัฒนะ แขวงทุ่งสองห้อง เขตหลักสี่ กรุงเทพมหานคร 10210 โทรศัพท์ 0 2142 1202 | อีเมล saraban@bde.go.th เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO): โทรศัพท์ 0 2142 1202 | อีเมล saraban@bde.go.th  13. การปรับปรุงคําประกาศ  เราอาจปรับปรุงคําประกาศนี้เมื่อมีการเปลี่ยนแปลงบริการ การประมวลผลข้อมูล หรือกฎหมาย โดยจะเผยแพร่คําประกาศฉบับปรับปรุงพร้อมวันที่มีผลบังคับใช้ผ่านแพลตฟอร์มหรือช่องทางที่เหมาะสม
